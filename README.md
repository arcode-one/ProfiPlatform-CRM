# ProfiPlatform · Кабинет управления

Локальная CRM на Vue 3, TypeScript и Vite. Использует Onest, знак и цвета стартовой страницы ProfiPlatform.

## Запуск

Используется Node.js 24. Выполни команды из папки этой задачи.

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 5186
```

Открой http://127.0.0.1:5186. Если PowerShell блокирует npm.ps1, используй npm.cmd.

## Как проверить

1. Войди с логином `demo` и паролем `demo` под отдельным демо-супервизором (роль № 1). В справочнике два примера сотрудников. У роли «Админ аккаунта» № 7 по умолчанию нет разрешений, у роли «Менеджер» № 27 включены просмотр и редактирование сотрудников.
2. В «Роли и права» создай роль с тегом. В группе «Сотрудники» отметь просмотр и редактирование карточек. Для доступа к списку нужен пункт просмотра соответствующего раздела. Создание, редактирование, отключение и восстановление ролей можно разрешить по отдельности.
3. В «Сотрудники» создай сотрудника с уникальным логином, в карточке открой вкладку «Роли», назначь роль и сохрани. Имя для отображения и должность хранятся отдельно от назначений.
4. Выйди и войди с логином этого сотрудника и демонстрационным паролем `demo`. Доступные разделы и действия зависят от его активных ролей. Для примера уже есть методист `v.lanskaya` с доступом к просмотру сотрудников.
5. Фильтр статуса, поиск, сортировка, дополнительные колонки и размер страницы доступны в списках. На телефоне таблицы прокручиваются внутри раздела. Карточка открывается в модальном окне по центру, длинная форма прокручивается внутри него.

## Локальное хранение

Справочники сохраняются в localStorage текущего браузера и адреса, ключ `profiplatform.directory.v1`. Вход действует во вкладке через sessionStorage. Все новые локальные сотрудники используют демопароль. Такой вход и клиентские проверки предназначены для макета приложения с тестовыми данными. Перед публикацией нужны серверные сессии, проверка прав и отдельная база аккаунта. Сетевых запросов к старой CRM приложение не отправляет.

## Структура проекта

| Путь | Что здесь находится |
| --- | --- |
| `src/App.vue` | Вход, выход и состояние сессии вкладки |
| `src/features/auth/` | Экран входа и восстановление доступа |
| `src/features/directory/` | Списки сотрудников и ролей в `DirectoryView.vue`, их карточки в `RecordDialog.vue` |
| `src/features/directory/model.ts` | Типы записей и значения для новых карточек |
| `src/features/directory/permissions.ts` | Группы разрешений и доступные действия в карточке |
| `src/features/directory/storage.ts` | Загрузка, обновление формата демоданных и сохранение с проверкой прав |
| `src/features/directory/demo.ts` | Начальные роли, примеры сотрудников и локальный супервизор |
| `src/components/` | Общие компоненты бренда и иконок |
| `src/assets/images/` | Логотип и изображения проекта |
| `src/styles/` | Токены дизайна, объявления шрифтов и стили интерфейса |
| `public/fonts/` | Onest Variable в WOFF2 для кириллицы и латиницы, лицензия OFL |
| `public/icons/` | SVG-спрайт Lucide 1.75.0 и лицензия |
| `docs/migration.md` | Сверка со старой CRM и задачи серверного этапа |

Новый раздел добавляй в свою папку внутри `src/features/`. Чтобы добавить иконку, помести её контуры в `public/icons/lucide.svg` как `symbol` с исходным именем Lucide и добавь имя в тип `IconName` в `src/components/Icon.vue`. Цвет берётся из CSS-свойства `color` родителя.

`npm run build` проверяет TypeScript и собирает проект в `dist`.
