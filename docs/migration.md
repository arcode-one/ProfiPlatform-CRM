# Сотрудники и роли

Проверено 18.11.2026. Для сравнения локально сохранены пять файлов Vue 2 из корня старой CRM. Копии хранятся рядом с задачами в папке «Архив/Исходники CRM». Они не входят в клиентскую сборку.

| Файл в FTP | Проверенная логика |
| --- | --- |
| /users.vue | Список и фильтры сотрудников, создание, открытие карточки. Конверт вызывает отправку ссылки через php/send_reset_link.php. |
| /edit_users.vue | Отображаемое имя и ФИО, логин, пол, контакты, должность, несколько ролей, примечание, Telegram, MAX, статус. Системные назначения 1 и 7 в карточке недоступны для изменения. |
| /roles.vue | Список ролей, фильтры, запросы чтения и сохранения роли и отмеченных прав. |
| /roles1.vue | Ещё один вариант списка, вызывает php/role.php. Подключение этого варианта в рабочей навигации не проверялось. |
| /roletree.vue | Вложенные пункты доступа, получение дочерних узлов через query_roles.php, отметки конкретной роли. У отдельных узлов есть ограничение на изменение администраторских прав. |

## Локальная версия

Для первого показа супервизор создаёт роль, выбирает разрешения и назначает роль сотруднику. После входа сотрудник видит разделы и действия, разрешённые его активными ролями. В карточке роли две группы разрешений. Каждое действие можно увидеть сразу. На компьютере группы стоят рядом, на телефоне идут друг за другом.

| Действие в старой CRM | Локальная версия для первого показа |
| --- | --- |
| Посмотреть список и открыть карточку сотрудника | Есть. Для доступа к разделу нужно право просмотра сотрудников. |
| Создать сотрудника, редактировать ФИО, логин, должность, контакты и примечание | Есть. Создание и редактирование разрешаются отдельно. Должности пока взяты из тестового списка. |
| Отключить или вернуть сотрудника, назначить несколько ролей | Есть. Изменение статуса и назначение ролей имеют отдельные разрешения. Назначения системных ролей № 1 и № 7 защищены. |
| Открыть список ролей и посмотреть права | Есть. Для доступа к разделу нужно право просмотра ролей. Обе системные роли доступны для просмотра. |
| Создать, редактировать, удалить и восстановить роль | Четыре независимых разрешения. Удалению в старом списке соответствует отключение роли с сохранением назначений. Восстановление возвращает её права сотрудникам. |
| Искать, сортировать, фильтровать и листать записи | Есть общий поиск, фильтр статуса, сортировка по коду и названию, страницы. Для сотрудников есть дополнительный фильтр по роли и показ контактных столбцов. |
| Отмечать строки, фильтровать по отдельным столбцам, настраивать столбцы и сохранять настройки списка | Полного аналога пока нет. |
| Добавить карточку сотрудника в закладки, окончательно удалить отключённого сотрудника | Пока отложено. |
| Выслать ссылку сотруднику на почту | Требуется почтовый сервис. На экране входа реализована локальная форма восстановления по логину. |
| Регистрация сотрудника по коду и экспорт списка в Excel | Пункты есть в старом дереве доступа. Выполнение операций не проверялось. В локальной версии их пока нет. |

В двух разделах менеджеру № 27 по умолчанию доступны просмотр и редактирование сотрудников. Админ аккаунта № 7 автоматически прав не получает. Логин `demo` использует отдельную роль супервизора № 1. Права старой CRM сверялись по карточкам ролей и PHP-коду. Справочник для всего продукта и серверные проверки предстоит подключить на этапе интеграции.

## Подключение базы

По описанию Дмитрия, в базе crm используются users, roles, acc, users_roles и roles_acc. Структура полей и ключи в базе ещё не проверялись. Изучение пяти клиентских файлов подтвердило вызовы php/users.php для карточек и должностей и php/query_roles.php для ролей, дерева и назначений. Клиентские вызовы не подтверждают контракт нового API.

Следующий этап: получить структуру таблиц и разрешённую тестовую базу отдельного аккаунта, сверить справочник должностей, точное дерево acc и правила системных прав, согласовать API входа, приглашений и изменения записей. Проверять права и принадлежность записей аккаунту на сервере. Сохранение карточки и связанных назначений выполнять в одной транзакции.
